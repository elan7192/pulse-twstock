# PULSE 脈動（GitHub Pages 版）

台股研究工具：分點籌碼、處置股、個股期貨與保證金、權證試算、可轉債（生命週期、鄭大選債、CBAS 拆解）、地板天花板、融券回補；交易計劃（期貨五條線、市場溫度計、樂透 OP、A+ 交易醫生）。

網站是純靜態頁面，部署在 GitHub Pages。資料由 GitHub Actions 每個交易日台北 15:40 與 21:30 從公開來源抓取，存進 `data/` 後重新發布。

## 資料來源

| 內容 | 來源 |
| --- | --- |
| 處置股、注意股、注意累計異常 | 證交所 OpenAPI、櫃買中心 OpenAPI |
| 融資融券、個股日成交、股東會（最後回補日） | 證交所 OpenAPI、櫃買中心 OpenAPI |
| 上市股票歷史（MA20、地板天花板） | 證交所每日收盤行情 MI_INDEX，逐日累積約 8 個月 |
| 個股期貨行情、股票期貨保證金 | 期交所 OpenAPI |
| 可轉債日行情、賣回權、變更交易 | 櫃買中心（端點參考 tw-cb-data 專案） |
| 加權指數歷史（五線譜、溫度計位階） | 證交所 MI_5MINS_HIST，每月一次請求，保留約 42 個月 |
| 台指期近月日 K（五條線） | 由期交所期貨每日行情逐日累積 |
| 公司總部縣市（主力地圖・地緣券商） | 證交所 t187ap03_L、櫃買 mopsfin_t187ap03_O 公司基本資料地址 |
| 台指選擇權（樂透 OP、P/C 比） | 期交所 OpenAPI DailyMarketReportOpt，只保留 TXO 一般時段 |

分點資料（證交所買賣日報表）需人工輸入驗證碼下載，網站不自動抓；可在「分點籌碼 → 匯入資料」匯入 CSV，只在瀏覽器處理。可轉債轉換價沒有允許自動讀取的公開來源，請在「可轉債 → 轉換價設定」貼上。

## 分點籌碼（介面參考籌碼K線電腦版）

- **自選股群組**：左側可切換群組，每檔旁「+」加入目前群組；「✎ 編輯」開啟編輯視窗：左側分類（全部個股、今日主力買超、主力連買、集中度、家數差為負）可「全部加入」，右側可新增／改名／刪除群組、輸入或一次貼上多檔代號（Ctrl+V 或「從剪貼簿貼上」）、排序與移除。只存在瀏覽器。
- **主力地圖**：區間內各縣市分點淨買賣的台灣方格地圖，標出公司總部；與總部同縣市的「地緣券商」列出並在買賣超 TOP15 加上「地緣」標籤。
- **分點調查局・熱門券商組合**：當日所有個股的「分點 × 個股」淨買賣金額排行，點選直接開該股並疊加分點。

## 交易計劃

概念參考「A+ 交易醫生」公開介紹（盤前五條撐壓線、溫度計、結算日樂透單、交易紀律）；該服務的實際公式沒有公開，這裡全部用公開指標自行實作，參數可調：

- **期貨五條線**：前一日高低收算 CDP（AH／NH／CDP／NL／AL）、樞紐點或費波那契樞紐；依參考價所在區間給當日劇本，並回測隔日觸及率與守住率。旁邊附加權指數五線譜（線性回歸 ±1σ、±2σ）作長線位階。
- **溫度計**：上市普通股站上月線／季線比例、5 日上漲家數比、20 日新高減新低、指數五線譜位階，加權成 0–100，分冰點／偏冷／中性／偏熱／過熱。
- **樂透 OP**：台指選擇權各週選／月選，篩出低權利金價外合約，列出損益兩平、到期價內機率（BS）、指數漲跌 1–5% 的倍數，以及固定預算下的口數與出場價。
- **A+ 交易醫生**：下單前 A+ 檢核（順溫度計、在五條線關鍵位、風報比、停損、情緒、計劃內）決定評級與口數；交易日誌（只存在瀏覽器）計算勝率、賺賠比、期望值、回撤，診斷砍大抱小、凹單、報復加碼、過度交易等問題。

## 請求原則

- 同一主機請求至少相隔 1.5–4 秒；遇 403／429 立即停止該主機。
- 失敗時保留上次資料；不跟隨轉址、不輪替 IP。
- 首次執行會補約 170 個交易日的上市股票歷史（約 12 分鐘），之後每天只多 1 次。

## 目錄

- `src/`：前端（React）與計算邏輯
- `scripts/fetch-data.mjs`：抓資料（`--only=plan` 只更新交易計劃資料）；`scripts/build.mjs`：打包網站到 `dist/`
- `data/`：由 Actions 產生並提交的資料
- `tests/`：公式、解析與示範資料測試（`npm test`）

## 本機執行

```sh
npm install
npm test
npm run fetch   # 需要能連到證交所、櫃買、期交所
npm run build
npx serve dist
```

研究用途，非投資建議。
